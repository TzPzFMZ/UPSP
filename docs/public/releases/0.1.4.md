# UPSP 0.1.4｜移除本地流式字符数上限

> Windows x64 · Base / Seed · 正式版 0.1.4。安装器未签名。

0.1.4 是一次小范围修复：模型持续输出较长的正文或思考内容时，UPSP 不再因本地累计字符数超过阈值而提前终止响应。

## 更新内容

- 移除共享流式读取链中对正文与推理内容合计字符数的熔断，长输出后返回的工具调用可以继续正常接收。
- 移除设置页中的“流式内容超限窗口”及其配置入口；旧配置中的 `stream_content_overrun_chars` 在读取时忽略，保存时剔除，读取本身不回写文件。
- 模型服务端输出 Token 限制、连接等待、首块和空闲超时、手动停止及不完整响应检查继续有效。

## 升级与边界

退出正在运行的 UPSP 后运行安装器，沿用原安装目录。程序升级与位格数据分离；历史 Round 和已有超限事件不改写。正式 GUI 布局未改变。

本次使用隔离数据进行定向回归与安装升级验证，无新增真实模型调用或 dogfood 运行证据。既有能力与限制见 [0.1.3 更新说明](0.1.3.md)。
