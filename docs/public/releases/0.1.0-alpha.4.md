# UPSP 0.1.0-alpha.4

这是 UPSP 当前桌面产品的首次公开 Alpha 候选。

## 本版包含

- Windows 11 x64 桌面壳与 Program Files 安装器；
- Windows“文档”位格数据根与 LocalAppData 本机设置分离；
- 阿廖沙快速初始化和自定义位格创建；
- 多模型服务目录、三阶段主／备用路由与 180 秒暂态重试；
- 常驻 Runtime、停止生成、本地善后和无重放崩溃恢复；
- OpenAI Chat、OpenAI Responses 与 Anthropic Messages 三协议流式输出；
- 连续历史对话、Markdown、工具轨迹、上下文审阅和协议中心；
- 中英文界面、完整产品源码、MIT 与第三方许可清单。

## 验收状态

- 已在 Windows 11 虚拟机验证新装、自定义中文空格路径、初始化、托盘、第二实例、端口冲突、同版修复、降级阻断、卸载／重装数据保留和进程树强退回收。
- 已使用本地 mock provider 验证三协议、暂态重试、停止与流式事件。
- 当前用户已手动体验真实流式交互，但它不替代可重复的正式 provider canary。

## 已知限制

- 安装器未签名，Windows 可能显示未知发布者或 SmartScreen 警告。
- 只正式验证 Windows 11 x64；Windows 10 尚未完整验收。
- 当前只有一个活动位格、一个主实例和一条对话线程。
- 多位格、分身、器官系统、暂停／继续、自动更新和云同步尚未实现。
- GUI 流式排版、动效与细节仍处于 Alpha 打磨阶段。
- 验收镜像自带 WebView2，真实“缺失 WebView2 后在线安装”路径仍未正验。
- 不保证所有 OpenAI／Anthropic 兼容中转服务都完全遵循官方协议。

## 数据与卸载

- 位格、记忆和 Round：`文档\UPSP`
- 模型服务、密钥、界面设置和缓存：`LocalAppData\UPSP`
- 卸载和覆盖安装不会删除以上数据。

## 校验

发布附件中的 `SHA256SUMS.txt` 是安装器校验真源。只从本仓库 GitHub Releases 下载候选文件。
