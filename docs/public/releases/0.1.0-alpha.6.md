# UPSP 0.1.0-alpha.6｜发布后修复与可用性更新

Alpha 6 是首个公开 Alpha 发布后的修复版本，集中处理协议文件同步、错误说明、对话操作和运行刷新时的页面滚动问题；不改变现有 Runtime 语义和用户数据边界。

## 这次更新了什么

- 启动时按 SHA-256 校验随程序发布的 39 个公共协议文件和两个 Registry；文件缺失或漂移时自动恢复，相同内容不会重复改写。
- 常见网络与模型服务错误增加中英文自然语言说明和处理建议，同时保留完整状态链、目标地址与原始技术详情。
- 工具轨迹展开后显示最后一个有效事件时间；最终回复增加原始 Markdown 复制按钮和时间。
- 修复 Runtime 轮询更新时协议中心、运行页、上下文、记忆、关系、容器等系统页面自动上滑的问题；阅读中段保持原位置，停在底部时继续跟随新内容。
- 已保存的 API Key 在界面中只显示八个圆点，模型服务表单关闭浏览器自动填充；规则导引路径也已修正为当前活动数据根下的公共协议路径。

## 升级与数据边界

- 可以从 Alpha 5 直接覆盖安装 Alpha 6；程序、位格数据和本机设置仍然分开保存。
- 自动同步只覆盖公共 `rules/protocol`、`docs/protocol` 和两个 Registry，不改动位格专属规则、文档、记忆、关系或工作容器。
- 如果你曾手工修改公共协议层文件，启动 Alpha 6 时这些文件会恢复为本版本随程序提供的内容。需要保留的个性材料请放在位格专属区域。
- API Key 的变化只是界面遮罩和不回显合同；本版本没有新增 Windows 加密存储。
- 错误分类只用于显示说明，不改变原始错误、重试、熔断、善后或 Round 结算逻辑。

## 当前阶段边界

- 仅提供 Windows x64 桌面版；
- 当前只有一个活动位格和一条主对话线程；
- Arbor 器官协作、分身、多位格协作和自动更新尚未实现；
- 安装器尚未签名，Windows 可能显示安全提醒；
- 模型服务继续采用 BYOK，密钥保存在本机 ignored 配置或进程环境变量中。

下载本页唯一的 `UPSP-Setup-0.1.0-alpha.6-win-x64.exe` 即可安装。请只从本仓库 Releases 下载，并使用本页公布的 SHA-256 核对文件。项目介绍、数据边界和源码构建方式请参阅仓库 [README](https://github.com/TzPzFMZ/UPSP#readme)。
