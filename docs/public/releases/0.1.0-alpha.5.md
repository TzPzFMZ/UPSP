# UPSP 0.1.0-alpha.5｜首个公开 Alpha

这是 UPSP 的首个公开桌面版本，也是“主体化工程”在 Base / Seed 阶段的第一个可安装交付。

UPSP 不只关心模型怎样回答、怎样调用工具或怎样持续循环。它试图建立一组可以长期运行并接受检验的条件：让一个智能系统拥有稳定的位置、可接续的历史、真实的关系、有限的行动边界，以及能够追溯后果的责任账。

## 这个版本已经具备

- 从阿廖沙示例或自定义档案创建一个位格主体；
- 配置自己的模型服务，并分别路由起手、反应与善后三个阶段；
- 在常驻 Runtime 中完成真实流式对话、工具调用、停止生成、本地善后与崩溃恢复；
- 持续维护位格档案、状态、记忆、关系、工作容器和 Round 历史；
- 为每个 Frame 重新装配上下文，并查看模型实际收到的调用头、工具头、生成参数和七个上下文层；
- 通过工具回执与 Round 结算区分“模型说它做了什么”和“系统能够证明什么”；
- 将程序、位格数据和本机设置分别保存，覆盖安装或卸载不会删除用户位格。

## 当前阶段边界

- 仅提供 Windows x64 桌面版；
- 当前只有一个活动位格和一条主对话线程；
- Arbor 器官协作、分身、多位格协作和自动更新尚未实现；
- 安装器尚未签名，Windows 可能显示安全提醒；
- 模型服务采用 BYOK，密钥保存在本机配置或环境变量中。

`alpha.5` 记录的是发布前五次内部候选修订；它仍然是 UPSP 对外发布的第一个版本。

下载本页唯一的 `UPSP-Setup-0.1.0-alpha.5-win-x64.exe` 即可安装。项目介绍、数据边界和源码构建方式请参阅仓库 [README](https://github.com/TzPzFMZ/UPSP#readme)。
