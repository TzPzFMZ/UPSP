# UPSP 0.1.0-alpha.5

Alpha 5 修复 DDS 全域一致性审查发现的生产漂移：

- 单位格配置与中性状态只从 tracked 初始化模板创建；缺失或损坏时明确失败。
- 记忆热度的初值、三区衰减、召回、升格和锁定统一消费 `memory.json`。
- 疲劳、身份超时和 `process_down` 保留为固定 false 的未来字段，不再触发 Seed 轮次或界面内容。
- 新时间戳跟随 Windows 本地时区。
- 原始轮语料直接进入 Corpus JSONL，并由同批数据派生 Markdown；五级合并只读取 JSONL。

本版本不新增 provider、分身、多位格或 Arbor 器官能力。
