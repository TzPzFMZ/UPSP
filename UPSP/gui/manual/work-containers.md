# 工作容器

工作容器是 UPSP 的生产器官。它们不应该被 UI 统一压成普通卡片列表。

首批页面语法可以这样理解：

- DC 辩证链：矛盾节点、正反合、证据链。
- EC 事件链：时间线、因果关系、证据回放。
- PRJ 项目容器：阶段、里程碑、验收、风险。
- SKL 技能容器：技能矩阵、熟练度、反省日志。

容器页面能独占中央主舞台。对话舱在右侧，不应压扁容器页面。
