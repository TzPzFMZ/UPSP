# 记忆总线

MEM 不是“又一个文件夹”。它是记忆条目的总线和存储层。

记忆条目可以被多个工作容器引用和挂接。一个记忆条目的繁荣度不需要靠“召回次数”这种自我计数来表达，更重要的是：

- 挂接了多少容器。
- 最近是否被装配到上下文。
- 是否有回执链和审计来源。
- 是否正在形成新的工作容器或长期沉淀。

v4 的记忆总线页面应给用户看：条目、挂接、生命周期、上下文可见性和审计指针。

记忆总线主页面只保留轻量索引；点击任一记忆条目后，统一详情弹窗显示完整元数据。记忆正文中的字段按“字段／内容”两列表格排版，长摘要自动换行；非字段内容仍按 Markdown 显示，Runtime 真源保持只读。
