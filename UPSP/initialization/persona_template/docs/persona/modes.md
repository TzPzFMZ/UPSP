# 位格活动模式参数·位格层

> 消费方式：脚本查表——模式切换时读本文件 → 与协议层合并 → 装配模式 prompt
> 注入模块：不直接注入（脚本内部消费，产出注入 RULES）
> 触发：起手步模式判断、模式切换

---

## 一、文件定位

本文件是位格对协议层预设模式参数（docs/protocol/base/modes.md）的覆盖与扩展。两层叠加：脚本先读协议层获取预设模式定义，再读本文件按规则合并——同 ID 模式位格层字段覆盖协议层，新 ID 模式作为位格自定义追加，禁用声明从候选清单中移除。

---

## 二、内容框架

本文件在运行时由善后步和节律点逐步填充。三个维度：

模式覆盖——对协议层预设模式的 prompt 和 constraints 做局部调整，格式为 JSON 含 id 和 override 字段（只需写覆盖的字段，其余保留协议层原值）。自定义模式——位格新增的协议层不存在的模式，格式与协议层一致，含 id、name、category、prompt 和 constraints。禁用清单——列出位格不使用的预设模式及其原因。

节律点自动更新模式统计数据（总激活次数、最近激活轮、平均持续轮数），供起手步模式判断参考。

---

*本文件初始可空或含位格创建时的基础覆盖。运行时由善后步和节律点逐步填充。*
