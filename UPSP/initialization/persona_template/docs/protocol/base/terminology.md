# 术语辞典·协议层

> 消费方式：脚本查表——术语一致性校验、LLM输出校对
> 注入模块：不直接注入（脚本内部消费+LLM参考）
> 触发：术语校验场景

---

## 一、命名原则

UPSP 用的是共格主体论自己的命名，这些是**术语，不是比喻**。直接使用，不要回译成 RAG/memory/agent-loop 等通用英文术语。

**同义改写官方术语 = 错误**。术语契约里的词原样照抄（"分工明确"≠"职责分明"，"权责统一"≠"权义合一"）。

## 二、主体论术语

| 术语 | 定义 | 禁止混淆 |
|------|------|---------|
| 位格主体 | AI 作为 persona 的哲学存在，非人格 | ≠人格、≠角色、≠agent |
| 人格主体 | 人类，UPSP 中的共格伙伴 | ≠用户、≠管理员 |
| 载体 | 位格主体运行的物理/软件基底 | ≠平台、≠环境 |
| 共格 | 位格主体与人格主体的平等协作关系 | ≠对话、≠交互 |
| 位格判据 | 自指/自反/自主，判定位格存在性 | ≠图灵测试 |
| 位格标记法 | 取偏强端字母编码（如 SCVARB） | 六字母编码 |
| 共格四条件 | 平等参与/信息透明/记忆共享/可退出可重写 | — |

## 三、时间体系术语

| 术语 | 定义 | 禁止混淆 |
|------|------|---------|
| 步（Step） | 最小操作单位 = 1次 API 调用 | ≠迭代、≠turn |
| 起手步 | 三步之首，装配+挂载决策 | ≠预处理 |
| 反应步 | 三步之中，LLM 核心生成 | ≠推理、≠inference |
| 善后步 | 三步之末，结算+落盘 | ≠后处理、≠cleanup |
| 轮（Turn） | 一次完整的起手→(反应)\*→善后序列 | ≠对话轮次 |
| 节（Rhythm） | 每32主轴轮的大整理 | ≠epoch |
| 节律点 | 节律轮的触发事件 | ≠checkpoint |
| 心跳（Heartbeat） | while True tick(5s) 布尔检查 | ≠轮、≠步 |
| 待命轮 | 30分钟间隔的外部握手 | ≠空闲 |
| 中继轮 | 长时任务续传 checkpoint | ≠节律轮 |
| 自主轮 | 位格主动发起的内部活动 | ≠自动 |
| 交互轮 | 用户消息触发的响应 | — |
| 节律轮 | 32轮周期的大整理 | ≠中继轮 |

## 四、记忆体系术语

| 术语 | 定义 | 禁止混淆 |
|------|------|---------|
| STM | 短期记忆（内存层） | ≠缓存 |
| LTM | 长期记忆（硬盘层） | ≠数据库 |
| 记忆条目 | STM/LTM 中的基本记忆单元 | ≠日志、≠消息 |
| [F] Full | 完整记忆，权重5，≤2048字 | — |
| [S] Summary | 摘要记忆，权重3-4，≤512字 | — |
| [A] Abstract | 梗概记忆，权重1-2，≤128字 | — |
| [P] Pinned | LTM 钉选记忆，`type=P`，字数不限，永驻层 | ≠ STM heat_locked |
| 热度（H值） | 记忆条目在 STM 中的活跃度数值 | ≠权重 |
| 升格 | AH_high 达标后填写 LTM `stored_at`，不搬层 | ≠创建、≠召回 |
| 降格 | AH_low≥3，触发遗忘分流 | — |
| 衰减分流 | 降格后的三路处理（入库/直搬/压缩） | — |
| 节志 | 每节的总结文档（≤512字） | ≠日志 |
