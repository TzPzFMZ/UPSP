## 三、元数据字段（第二层，Base层24字段）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 8位十六进制 TTTTTNNN |
| type | string | F/S/A/P，P为钉选锁定层 |
| weight | int | 0-5，决定目标形态；未入库 STM 遗忘可同步降权，入库后不变 |
| title | string | 标题（≤16字） |
| dream | boolean | 是否由梦境素材升格而来 |
| created_at | ISO8601+偏移 | 创建时间 |
| stored_at | ISO8601+偏移或空串 | 首次正式入库时间；未入库为空，填写后永久不变 |
| last_recalled_at | ISO8601+偏移 | 最后召回时间 |
| created_round | int/null | 创建轮号 |
| created_instance_id | string | 创建该记忆的分身 ID |
| last_recalled_round | int/null | 最后召回轮号 |
| last_recalled_instance_id | string | 最后召回该记忆的分身 ID |
| source | string | "前端\|终端\|地点" |
| model | string | 产出模型标识 |
| subject | string | 记忆涉及的活动关系主体规范 ID |
| access | string | public/private |
| recalled | boolean | 是否曾完成回忆重整 |
| current_overview | string | 现状概况，≤128字，非空时引用最新挂接容器 |
| current_overview_updated_at | ISO8601+偏移/string | 现状概况最后真实变化时间；未知为空字符串 |
| tags | string[] | 语义标签（软链接） |
| linked_containers | string[] | 关联工作容器编号（硬链接） |
| decay_period_days | int | 衰减总周期天数 |
| decay_countdown_days | int | 衰减倒计时 |
| media | string[] | 附属媒体文件路径 |

### subject 字段格式

当前 Seed 只接受一个活动关系主体字符串。输入可使用关系卡 `id`、`name` 或精确 `aliases`，处理器统一保存 Registry 规范 `id`；主体自身由当前关系 Registry 中 `category=self` 的规范 ID 表示。工作对象用 `linked_containers` 表达；隐私功能当前冻结，不复用 subject 特殊值。

## 四、正文词条格式（第三层）

```markdown
### {编号}

正文内容……

---
[即时感受]
交互: {感受词(强度)}, ...
关系: {对象/感受词(强度)}, ...
```

- 即时感受绑定 created_at
- 召回只更新挂载、热度与完成回执，不修改旧正文或新增感受段
- 感知带宽上限：交互感受 ≤3个/轮，关系感受每个关系主体 ≤2个/轮

## 五、特殊形态

### Pinned [P]（钉选记忆）

| 属性 | 规则 |
|------|------|
| 字数上限 | 无限制 |
| 衰减 | LTM 永驻层，不参与普通冷备删除；召回 STM 后正常热度 |
| 钉选权限 | 位格主体按语义选择锁定，脚本执行搬层；解锁后按当前 weight 回 F/S/A |
| 目录结构 | 与 Full/Summary/Abstract 一致 |

STM 热度锁定另用 `heat_locked` 表达，固定 H=80，和 Pinned [P] 不是同一个机制。

### 隐私功能冻结

当前 Seed 不生成隐私记忆或公开/脱敏投影；`access` 继续只保留 `public/private` 兼容形状，不新增 `redacted`。历史私密数据对模型与 cleanup fail closed，重新启用前另行裁决归属、授权、投影生命周期与事务回滚。

### ×（已订正）条目

走正常衰减流程，不单独隔离。辩证标记在 Dialectics/ 追踪。来时路不销毁只沉淀。

## 六、多媒体压缩标准

> **目标标准／当前 deferred**：`media` 字段只保留兼容形状。当前 Seed 尚未开放图片 ingress、provider image block、媒体转换或记忆媒体生命周期；以下参数不得冒充已经运行的生产能力。

## 七、梦境素材配比

| 素材池 | 比例 | 说明 |
|--------|------|------|
| [F] 完整记忆 | 5% | 清晰记忆偶尔入梦 |
| [S] 摘要记忆 | 10% | 半模糊，适合梦境 |
