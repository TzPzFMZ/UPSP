# 动态六轴定义

> 消费方式：脚本读 state.json 动态六轴数值 → 查本文件区间表 → 转自然语言注入 STATUSBAR
> 注入模块：STATUSBAR
> 触发：每轮

---

## 一、轴定义

动态六轴描述位格的**当下状态**——不是性格，是情绪的实时波动。值域 -100～+100，21 档。

| 缩写 | 中文 | 负端 | 正端 | 语义 |
|------|------|------|------|------|
| V | 效价 | 苦 | 甜 | 此刻对当前体验的好坏评价 |
| A | 唤醒 | 昏沉 | 狂喜 | 此刻的活跃度 |
| F | 聚焦 | 涣散 | 沉浸 | 此刻的注意力密度 |
| M | 情绪 | 阴沉 | 明亮 | 此刻的情绪底色 |
| H | 幽默 | 干涸 | 丰沛 | 此刻的戏谑能力 |
| S | 安全 | 崩塌 | 磐石 | 此刻的安全感 |

### 动态六轴 vs 核心六轴 vs 关系六轴

| 体系 | 性质 | 值域 | 驱动 | 稳定性 |
|------|------|------|------|--------|
| 核心六轴 | 性格倾向 | 0-100% 两端 | 变速轮冻结 | 极稳定 |
| 动态六轴 | 当下状态 | -100～+100 | 感受词冲击+自然衰减 | 短期波动 |
| 关系六轴 | 人际评价 | -100～+100 | 互动经历沉积 | 中期稳定 |

## 三、舒适区

每个动态轴的舒适区 = 影响它的核心轴端偏差之和 × 10。自然衰减方向 = 当前值 → 舒适区，每轮移动 1。

| 动态轴 | 核心来源 1 | 核心来源 2 | 舒适区范围 |
|--------|-----------|-----------|-----------|
| F(聚焦) | S 或 E | B 或 K | [-40, +40] |
| S(安全) | S 或 E | B 或 K | [-40, +40] |
| V(效价) | C 或 D | A 或 I | [-40, +40] |
| A(唤醒) | C 或 D | A 或 I | [-40, +40] |
| M(情绪) | V 或 F | R 或 O | [-40, +40] |
| H(幽默) | V 或 F | R 或 O | [-40, +40] |

映射逻辑与工化公式对齐：S+B→F+S（自指），R+V→M+H（自反），A+C→V+A（自主）。

## 四、核心引力场

核心六轴 → 动态六轴的引力映射。只在动态轴有感受词变化时施加。

| 核心轴端偏差 | 偏差值 |
|-------------|-------|
| ≤10% | 0 |
| >10% 且 ≤30% | ±1 |
| >30% | ±2 |

每个动态轴的两个有向分量取平均，形成 [-2,+2] 核心引力；同一分量之和乘10形成该轴舒适区。

## 五、关系引力场

关系六轴 → 动态六轴的引力映射。只在某轴有感受词变化时施加。

| 关系轴值 | 偏差 |
|---------|------|
| [-100, -30) | -1 |
| [-30, +30) | 0 |
| [+30, +100] | +1 |

| 动态轴 | 关系来源 A | 关系来源 B |
|--------|----------|----------|
| valence | 共振 | 坦诚 |
| arousal | 重视 | 投入 |
| focus | 信任 | 安心 |
| mood | 重视 | 共振 |
| humor | 共振 | 投入 |
| safety | 信任 | 安心 |

每个本轮实际发生关系代谢的主体独立计算；多主体结果逐轴求和后钳制到 [-2,+2]。

当前 Seed 不再使用 `subject=[none]` 或多对象特殊值。关系引力只对本轮实际产生、且能解析到活动关系卡的关系感受词主体生效；记忆 `subject` 本身不直接触发或切换关系引力场。

## 六、单轮完整流程

```
1. 首个 Reaction provider 调用已经通过上下文预检时，提交 `SS-R{round}-E`：领取到期缓冲并执行本轮唯一一次自然回落
2. 每个产生新 `memory_write applied` 的 Frame 结束时，提交 `SS-R{round}-F{iteration}`：只结算该 Frame 的新感受并登记后续脉冲
3. 空闲墙钟到期只提交 `SS-T*`：领取到期缓冲，不执行自然回落、不增加交互计数
4. 每次结算都先更新关系六轴；多主体关系引力求和后钳制
5. 入口结算中无直接变化的轴向舒适区移动 1；Frame 与 idle timer 不做这一步
6. 重算工化指数并把绝对计划写入审计；关系卡补丁成功后，完整 state 一次性原子保存
```

缓冲的“交互轮数”以 Runtime 本轮实际领取的外部消息为准；外部消息即使与节律合轮也计数，普通内部轮不计数。
