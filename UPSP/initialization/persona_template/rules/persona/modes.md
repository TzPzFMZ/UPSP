# 位格活动模式规则·位格层

本文件记录位格对活动模式的软覆盖、自定义和禁用偏好。协议层 `protocol/base/modes.md` 定义模式的基本边界；本文件只调整位格自己的表达姿态和注意力倾向。

## 一、定位

位格层模式不能制造轮类型，不能改变步骤权限，不能覆盖工具契约、体界系统、关系分类、隐私规则或审计要求。

当协议层、状态栏、弹窗层、工具指南和本文件出现冲突时，执行顺序以当前运行时装配和协议层硬边界为准。本文件只作为按需参考。

## 二、条目内容

模式覆盖应说明：目标模式、覆盖字段、适用条件、强度和来源。覆盖只作用于明确字段，未写明字段仍按协议层和当前 docs 模板处理。

自定义模式应说明：模式 ID、名称、用途、姿态、约束、适用场景和退出条件。禁用清单应说明禁用对象、原因、范围和复审条件。

## 三、更新边界

位格层模式可以进化，但不能凭一轮情绪永久改写。新增、修改、禁用或恢复模式，应有来源、理由和真实写入记录。临时状态只写交接或当步说明，不直接变成长期模式规则。
